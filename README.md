# Hoofdpijndagboek

Een kleine app om elke dag bij te houden of je hoofdpijn had, hoe erg, en een notitie.
Alles blijft op je eigen telefoon; er gaat niets naar internet.

**Open de app:** https://viezebadjasman.github.io/hoofdpijndagboek/

Installeren: open de link op je telefoon en kies "Zet op beginscherm" (iPhone, Safari)
of "App installeren" (Android, Chrome).

Meer uitleg (meldingen, automatisch openen, back-up): zie [LEESMIJ.txt](LEESMIJ.txt).
